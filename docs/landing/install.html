Setup guide · version 0.2.1

Install Hagent on your own computer

Hagent is downloaded and run locally. The website never receives your projects, prompts, credentials, or agent jobs.

Download source ZIPClone from GitHub
Recommended first setup: Windows 11, Python 3.11+, Git, and either Ollama or one authenticated AI CLI/API provider.

1. Requirements

Required

Python 3.11 or newer, a modern browser, and enough disk space for the source and Python environment.

Choose at least one runtime

Ollama/LM Studio, a cloud API key, or an installed and signed-in CLI such as Codex, Claude Code, Gemini, or OpenCode.

2. Windows installation

1

Download and extract

Download the ZIP, choose “Extract all,” and open PowerShell inside the extracted folder.

2

Create the isolated environment

py -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
3

Install Hagent

.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -e .
4

Start it

.venv\Scripts\hagent.exe serve

Open http://127.0.0.1:8000. Keep the terminal open while Hagent runs.

3. macOS or Linux installation

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
hagent serve

Windows is currently the primary tested host. The web app is portable, but some terminal and local-CLI discovery paths still need broader macOS/Linux verification.

4. Verify the installation

hagent version
hagent doctor
hagent runtime list

You should see hagent 0.2.1. The dashboard should load locally and show an empty workspace ready for configuration.

5. Connect an AI provider

Open Runtimes → New runtime. For the easiest private start, run Ollama locally and choose an installed model. For cloud APIs, enter the provider key in Hagent’s runtime settings. Installed CLI runtimes reuse that CLI’s existing login.

Cost reminder: Hagent itself is source-available at no charge, but cloud model providers may charge for API usage. Local models consume your own RAM, CPU, and possibly GPU.

6. Update later

If you cloned with Git:

git pull
.venv\Scripts\python.exe -m pip install -e .

On macOS/Linux, replace the final command with .venv/bin/python -m pip install -e .. Back up hagent.db first.

7. Know where your data lives

By default, projects, agents, issues, memory, run history, and settings live in hagent.db in the working folder. Generated skill notes live under skill-notes/. Provider credentials remain local unless the chosen provider requires a cloud request.

8. Remove Hagent

Stop the server, then archive or remove the extracted Hagent folder. Preserve hagent.db and skill-notes/ if you want your workspace later. Hagent does not install a background service by default.
