What people usually want to know

Short answers about what Hagent is, what it costs, what leaves your machine, and whether this release is ready for you.

Can I use Hagent directly on this website?

No. Myhai.org is the product guide and download site. Hagent runs on your own computer or server after you install it.

Is Hagent free?

The repository can be downloaded from GitHub. Your chosen AI provider may charge API fees, while local Ollama/LM Studio models use your own hardware and electricity.

Does Hagent include an AI model?

No. It orchestrates runtimes you choose: local models, direct cloud APIs, compatible gateways, or installed AI CLIs.

What computer do I need?

The dashboard itself is lightweight. Cloud and CLI runtimes need modest resources. Local models may need substantial RAM or GPU memory depending on model size. Start with a smaller Ollama model if you are unsure.

Where is my data stored?

Hagent uses a local SQLite database, normally hagent.db, plus local generated files such as skill notes. Back these up before upgrades or major changes.

Does anything leave my computer?

The Hagent application and database stay local. Prompts sent to a cloud runtime necessarily go to that provider. Ollama or LM Studio can keep inference local. Repository links, web tools, and other integrations may also contact external services when used.

Can agents access my terminal and files?

Only agents with terminal access enabled can use it. They run with the permissions of the OS account running Hagent; a working directory is not a security sandbox. Prefer a dedicated account, container, VM, or isolated worker.

What is Holly?

Holly can serve as a designated terminal-capable operator agent: it receives tasks through Hagent, executes within the permissions you give it, and returns results to other agents. It is not a separate AI provider.

How does memory work?

Canonical memory stores scoped facts and preferences across supported providers. Skills can separately retain redacted lessons from relevant failures or verifier rejections, recalled only when useful.

Can I use Ollama?

Yes. Start Ollama, download a model, then create an Ollama runtime with the exact model name. Performance depends on your CPU, RAM, GPU, and model size.

Can multiple agents work together?

Yes. Agents can be organized into squads, delegated work, assigned staged issues, and paired with verifier agents. Concurrency and delegation limits keep the system bounded.

Can I access Hagent from another device?

Yes, but configure Hagent accounts first and protect traffic with HTTPS or a private network such as Tailscale. Never expose an unauthenticated terminal-enabled instance to the internet.

Is it as mature as a commercial platform?

Not yet. Hagent 0.2.1 has meaningful orchestration depth and extensive tests, but installation is still source-based and container packaging, automatic upgrades, and enterprise operations need more work.

How good is version 0.2.1?

For technical early adopters, the honest overall assessment is about 7.5/10: strong architecture, provider breadth, workflow modeling, and local control; average beginner setup; early production maturity. That is a product judgment, not a standardized benchmark score.

How do I update or uninstall it?

See the update and removal steps. Back up your database, pull or download the new source, and reinstall the editable package. Hagent does not create a background service by default.
