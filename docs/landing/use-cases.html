Practical patterns

Use Hagent as an operating layer for AI work

Hagent is most useful when work needs multiple roles, visible state, repeatable instructions, or human review—not when a single chat reply is enough.

Development

Plan, implement, and verify code

Create planner, developer, and reviewer agents. Break a feature into staged issues, attach repository resources, require approval, and keep the full run trail.

Research

Turn questions into reviewed briefs

Let a researcher gather evidence, a critic test claims, and an editor produce the final brief. Store durable preferences in canonical memory.

Operations

Run recurring checks

Use Autopilots for scheduled reports, backlog triage, or routine local checks. Escalate exceptions to the dashboard instead of hiding them in logs.

Content

Build a repeatable editorial pipeline

Combine voice, research, drafting, fact-checking, and final-review skills. Failed approaches can become reusable skill lessons.

Local AI

Coordinate Ollama specialists

Run private models for classification, summarization, drafting, or coding and route harder tasks to a cloud or CLI backup only when needed.

Personal systems

Manage ambitious solo projects

Keep decisions, issues, agents, and outcomes in one local workspace while you remain the approver and owner of the final result.

When Hagent is the wrong tool

One simple question

A normal chat interface is faster when there is no workflow, history, assignment, or review to manage.

Unsupervised high-stakes decisions

Do not delegate medical, legal, financial, security, or destructive actions without qualified human review.

Instant enterprise rollout

Version 0.2.1 is an early technical release, not a supported multi-tenant enterprise service.
